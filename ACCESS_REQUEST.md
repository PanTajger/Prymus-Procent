# ACCESS REQUEST — jak uzyskać dostęp do prywatnych komponentów

Dziękujemy za zainteresowanie prywatnymi komponentami projektu Prymus Procent.

Aby poprosić o dostęp do rdzenia (modele, skrypty treningowe, produkcyjne API), wykonaj proszę następujące kroki:

1. Otwórz nowe issue w tym repozytorium zatytułowane: "Access Request — <Nazwa_organizacji>". Oznacz "access-request" w treści.

2. W treści podaj:
   - Nazwa organizacji / osoby:
   - Kontakt (adres e‑mail):
   - Cel użycia (opis, w jakim celu chcesz uzyskać dostęp):
   - Zakres dostępu (np. modele/inference API/dataset):
   - Czy podpiszesz NDA? (tak/nie)

3. Autor projektu skontaktuje się w odpowiedzi i zaproponuje dalsze kroki, w tym warunki NDA/licencji oraz możliwy zakres udostępnienia.

Uwaga:
- Brak podpisanej umowy (NDA/licencja) oznacza brak dostępu do prywatnych artefaktów.
- W niektórych przypadkach dostęp może być udzielony tylko do celów akademickich lub demonstracyjnych po ograniczeniu zakresu licencji.

Dziękujemy za zrozumienie — ochrona pracy i danych uczniów to priorytet.
