# SECURITY

Jeśli znalazłeś lukę bezpieczeństwa w tym repozytorium lub w powiązanych usługach prywatnych, prosimy o odpowiedzialne zgłoszenie.

Preferowany sposób:
- Otwórz issue z oznaczeniem "security" **i** opublikuj minimalny opis problemu bez wrażliwych szczegółów.

Jeżeli chcesz raportować problem prywatnie (zawierający szczegóły exploitów), prosimy o kontakt poprzez GitHub Security Advisories lub e‑mail pod adresem: pantajger-security@example.com

Nie publikuj szczegółów technicznych exploitów w publicznych miejscach.
